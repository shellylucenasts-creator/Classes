JULIANA · CLASS 3 · 03/10

THE WEDNESDAY CHECK-IN

You manage a fictional team. The deadline is Friday.

The situation: It's Wednesday morning. A manager is checking what the team has completed, what is still pending, and when certain things happened.

Before listening: What information does a manager need before confirming a project launch?

DRILL · Have we finished...? / When did we...? · Question ↔ answer · Substitute: report / feedback / login issue
Reveal dialogue after listening

Good morning, everyone. Let's go over the project updates. Have we finished the report yet?

Yes, we've finished it. I sent the final version this morning.

Great. When did you send it?

At nine thirty this morning.

And have we received the client's feedback?

Yes, we have. They sent it yesterday afternoon.

Good. Have we fixed the login issue yet?

No, we haven't fixed it yet. We've found the problem, but we're still working on the solution.

When did you find the problem?

We found it late yesterday, after the last test.

Have you tested a new solution?

Yes, we have. We tested one this morning, but it didn't work.

Okay. What have you completed so far?

We've finished the report, collected the feedback, and identified the login problem.

And what haven't we finished yet?

We haven't fixed the login issue, and we haven't confirmed the launch date.

Why haven't we confirmed the date?

Because we need to fix the login issue first. We can review the date tomorrow.

All right. Please send me another update tomorrow morning. I need to know what's ready and what's still pending.

Of course. We'll send you the latest results before ten.

LISTEN · THE PROJECT CHECK-IN

Listen to the team meeting. Focus on the updates, not individual words.

First listen: Which tasks are finished? Which are still pending?

Second listen: What happened yesterday? What happened this morning?

After listening: What does the manager ask to check a result? What does the manager ask to find out when something happened?

Teacher: use the separate dialogue audio script. Do not display the transcript before listening.

NOTICING · RESULT OR PAST EVENT?

Compare what each question is trying to find out.

RESULT NOW

Have they released the update?

Yes, they have.

SPECIFIC PAST TIME

When did they release it?

They released it on November 6.

Which question checks the current result? Which asks about a finished event at a specific time?
